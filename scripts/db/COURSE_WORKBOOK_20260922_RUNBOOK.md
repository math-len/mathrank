# 2026-09-22 개정 단원표 안전 반영

대상 파일: `/Users/lee/Downloads/단원분류표(개정)(260922).xlsx`

## 원칙

- 이 작업은 누락된 단원만 추가한다.
- 기존 단원과 경로를 삭제하거나 이름으로 일괄 치환하지 않는다.
- 기존 문제는 course path를 참조하므로 삭제는 문제 매핑표와 별도 migration이 준비된 뒤 수행한다.

## 절차

1. 운영 DB 스냅샷을 생성한다.
2. `init-course` 프로필과 `excel.file.path`를 지정하되 `excel.course.apply=false`로 실행한다.
3. 로그의 유효 행 수가 원본 표와 맞는지 확인한다.
4. 스테이징 DB에서 `excel.course.apply=true`로 실행하고 중복·트리 깊이·문제 검색을 검증한다.
5. 같은 설정을 운영에서 한 번 실행한다. 초기화기는 이름+부모 경로 기준으로 기존 단원을 재사용한다.
6. 변경 전후 과정/단원 개수와 샘플 문제 검색 결과를 보관한다.

교육과정에서 제거된 과목은 이번 실행에서 비활성화 또는 삭제하지 않는다.
